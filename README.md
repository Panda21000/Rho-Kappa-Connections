# Rho Kappa History Connections

This is a complete static game. No build, dependencies, or installation are needed.

## Publish on GitHub Pages

1. Extract this ZIP on your device. Do not upload the ZIP itself.
2. Upload index.html and .nojekyll into the top level of your repository on main.
3. In repository Settings > Pages, choose Deploy from a branch.
4. Select main and / (root), then Save.
5. Wait for the Pages deployment to succeed in Actions.
6. Open the Visit site link shown in Settings > Pages.

The file must be named exactly index.html, not Index.html or index.html.txt.
If publishing from /docs instead, put index.html and .nojekyll inside /docs.
Do not copy the Markdown code fences into the HTML file.

HTML and JavaScript syntax were checked. A server 404 indicates a publishing or URL problem; changing game code will not configure GitHub Pages.
